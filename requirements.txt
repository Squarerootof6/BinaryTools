# Runtime dependencies for binary_tools
#
# Validated environment (2026-10):
#   Python 3.11.5 · NumPy 1.26.4 · TensorFlow 2.14.0 · Keras 2.14
#
# Why the pins:
#   * tensorflow 2.14.x is the last release that loads the bundled legacy
#     Keras-2.4 .h5 weight files through its own API.  binary_tools ships its
#     own h5py-based loader (gfp.load_legacy_weights), so newer TF works too,
#     but 2.14.x is the combination that has been verified end-to-end.
#   * TensorFlow 2.14 requires NumPy < 2.0 (NumPy 2 removes np.float/np.Inf,
#     which the codebase historically used; those were replaced, but the
#     TF/numpy ABI mismatch alone breaks TF 2.14 on NumPy 2).
#
